About:
A tool to sift through the dividendhistory monthly list of stocks. 
Using bs4, openpyxl, PIL, requests_html, and urllib to scrape the website and assign points to each stock based on personal preference. 
Then export a spreadsheet and an image corresponding to the filtered stocks.
The code was made in python3.8 with minor adjustments to libraries due to syntax errors between old and new Python versions.
